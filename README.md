# Welcome to my StoreSystem project!
Its juts a simple `CRUD` im creating to improve my skills in JAVA. At the moment I'm using just a `.csv` file to 
store the products, but in the future I want to put a real `DataBase`.

## How it works?
At this point it's simple as a pie, you just select what you want to do, manage the warehouse or be a client.
Managing the warehouse you can add products, remove products or update the stock.
Being a Client a list will appear with all the items in the warehouse, you will choose the items you want to add 
in your "Bag"
